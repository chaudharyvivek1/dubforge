**Why prose says twenty-three.** Every check above except `multiple_audio_tracks` is
emitted on a normal run — the container checks need a source and an output, which a run
has. A source with more than one audio stream adds `multiple_audio_tracks`, making
twenty-four. Any document that states a different number is wrong, and
`tests/test_docs_integrity.py` fails the build rather than trusting the prose.
